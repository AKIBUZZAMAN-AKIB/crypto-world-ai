| # | কাজ | অবস্থা | প্রমাণ |
|---|---|---|---|
| ১ | **CSV চার্ট-ডেটা এক্সপোর্ট** | ✅ | লেআউট মেনুতে `Export chart data` — `Visible` / `All` + `ISO`/`UNIX` টগল; রিয়েল ব্রাউজারে ৫০০ বার ডাউনলোড হয়েছে, হেডার `time,open,high,low,close,volume` |

| ৪ | **Snap to indicators (ম্যাগনেট)** | ✅ | ম্যাগনেট মেনুতে নতুন টগল; OHLC-র পাশাপাশি overlay ইন্ডিকেটরের মানও স্ন্যাপ-টার্গেট |

| ৬ | **Double curve · Gann square fixed · Pin · Fib pitchfan** | ✅ | চারটিই টুলবারে, ব্রাউজারে সত্যি এঁকে যাচাই করা |

### নতুন চারটি ড্রয়িং টুল — কীভাবে কাজ করে

* **Double curve** — একটাই কিউবিক বেজিয়ে: শুরু, শেষ, এবং **দুই** কন্ট্রোল পয়েন্ট (TV-র "Price 1/2/3/4")। প্রথম কন্ট্রোল প্রথম বাঁক, দ্বিতীয়টি দ্বিতীয় বাঁক।
* **Gann Square Fixed** — সাধারণ Gann Square চার্ট-এককে বর্গ থাকে; এটা **স্ক্রিন-পিক্সেলে** বর্গ: যে প্রস্থ টানা হয়, ঠিক তত পিক্সেল উচ্চতা। গ্রিড এখন বর্গাকার বক্সের ভেতরেই ভাগ হয় (আগে প্রাইস-স্প্যান ধরে ভাগ হচ্ছিল, ফলে রেখাগুলো বক্সের বাইরে চলে যেত — ঠিক করা হয়েছে)।
* **Pin** — মাথা + সরু ডাঁটি, ডাঁটির **ডগা** ঠিক দামের উপর; লেখার প্লেট পাশে, চুলকানি রেখায় জোড়া।
* **Fib Pitchfan** — তিনটি অ্যাঙ্কর: ট্রেন্ডের শুরু, ট্রেন্ডের চূড়া, প্রথম কারেকশনের চূড়া; প্রতিটি রে শুরু থেকে গিয়ে কারেকশন লেগের ০.২৩৬ … ১.০ ভাগ বিন্দু দিয়ে যায়, তাই `0` = ট্রেন্ড লেগ আর `1` = আপনার তোলা কারেকশন পয়েন্ট।

## ৫. এখন কী ক্লিক করবেন

1. **চার্ট টাইপ মেনু** (টপবারের ক্যান্ডেল আইকন) → নিচে আটটি নতুন এন্ট্রি: Hollow candles, Volume candles, Line with markers, Step line, HLC area, Columns, High-low, HLC bars।
2. **Settings (গিয়ার) → Variant** গ্রুপ → hollow আপ, ন্যূনতম প্রস্থ, prev-close রং, মার্কার ব্যাসার্ধ, কলামের বেস।
3. **লেআউট বাটন (⌘ গ্রিড আইকন)** → নিচে `Export chart data` → `Visible` / `All`, পাশে `ISO`/`UNIX`।
4. **বাম টুলবার** →
   * Measurements → `Price Range`, `Date Range`
   * Shapes → `Double curve`
   * Fibonacci → `Fib Pitchfan`, `Gann Square Fixed`
   * Text → `Pin`
5. **ম্যাগনেট আইকনের পাশের তীর (chevron)** → `Snap to indicators`।

প্রিভিউ চলছে: `http://127.0.0.1:5190/` (Arena preview-তে `/workspace.html`)।
